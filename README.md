# backend-study-25-sns

과제 2: 게시글 CRUD API


## API 목록

| 기능 | Method | URL | 성공 | 실패 |
|---|---|---|---|---|
| 게시글 생성 | POST | /posts | 201 | 400 |
| 게시글 목록 조회 | GET | /posts | 200 | - |
| 게시글 단건 조회 | GET | /posts/{postId} | 200 | 404 |
| 게시글 수정 | PATCH | /posts/{postId} | 200 | 400, 404 |
| 게시글 삭제 | DELETE | /posts/{postId} | 204 | 404 |

- 제목은 100자, 내용은 500자까지 쓸 수 있다.
- 수정할 때는 보낸 필드만 바뀌고 안 보낸 필드는 그대로 남는다.
- 실패하면 `{"message": "실패 이유"}` 형태로 응답한다.

## AI 활용

전체적인 코드는 AI를 사용해서 작성했고, 중요한 코드 부분만 직접 따라 치면서 공부했다.
