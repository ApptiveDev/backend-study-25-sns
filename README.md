# backend-study-25-sns

## 게시글 CRUD API 구현

### 개발 환경
- Java 17
- Spring Boot 3.5.16
- Gradle
- Spring Data JPA
- H2 Database

### 구현 기능
- 게시글 생성, 전체 조회, 단건 조회, 수정, 삭제
- 제목 및 내용 입력값 검증
- 존재하지 않는 게시글에 대한 404 예외 처리
- PATCH 요청에서 전달된 필드만 수정
- 오류 응답 메시지 통일

### API 명세

| Method | URL | 기능 | 성공 상태 코드 |
|---|---|---|---|
| POST | `/posts` | 게시글 생성 | 201 |
| GET | `/posts` | 전체 조회 | 200 |
| GET | `/posts/{postId}` | 단건 조회 | 200 |
| PATCH | `/posts/{postId}` | 게시글 수정 | 200 |
| DELETE | `/posts/{postId}` | 게시글 삭제 | 204 |

### 입력값 검증
- 제목은 최대 100자, 내용은 최대 500자까지 허용
- 생성 시 제목과 내용 필수
- 수정 시 하나 이상의 필드 필수
- null 또는 공백만 있는 값은 허용하지 않음
- 존재하지 않는 게시글을 조회·수정·삭제하면 404 반환

### 테스트
Postman으로 CRUD API와 400·404 오류 처리를 확인했습니다.

H2 파일 모드를 사용하여 서버 재시작 후에도 게시글 데이터가 유지되는 것을 확인했습니다.

### AI 활용
ChatGPT를 사용하여 Spring Boot의 계층 구조와 JPA, HTTP 상태 코드 등을 학습하고, 코드 작성 및 오류 해결 과정에서 도움을 받았습니다. 구현한 기능은 Postman으로 직접 테스트했습니다.
